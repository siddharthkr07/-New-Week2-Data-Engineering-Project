# Week 2: Relational Schema Merging & Multi-Source ETL Rules

## Project Title
E-Commerce Multi-Table Data Integration Engine

## Project Overview
This project demonstrates a complete ETL (Extract, Transform, Load) pipeline using Python and Pandas. The objective is to integrate multiple e-commerce datasets, perform SQL-style joins, clean duplicate records, standardize data, and generate important business KPIs.

## Objectives
- Merge multiple relational datasets
- Perform SQL-style joins using Pandas
- Handle duplicate records
- Standardize schema and data types
- Generate business KPIs
- Create visualizations for business insights

## Datasets Used
- customers.csv
- orders.csv
- payments.csv
- shipping.csv

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## ETL Process
1. Load all datasets
2. Clean duplicate records
3. Merge relational tables
4. Generate final integrated dataset
5. Calculate Customer Lifetime Value (LTV)
6. Generate Shipping Status Report
7. Create KPI charts
8. Export final CSV files

## Output Files
- final_merged_data.csv
- customer_ltv.csv
- shipping_report.csv

## Visualizations
- Customer LTV Chart

- Order Status Chart

## Business KPIs
- Customer Lifetime Value (LTV)
- Payment Status Distribution
- Shipping Status Distribution
- Order Status Distribution
